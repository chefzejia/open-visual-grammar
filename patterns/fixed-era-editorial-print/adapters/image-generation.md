# Image Generation Adapter / 生图 Adapter

Compile the `fixed-era-editorial-print` Pattern for the current visual argument.
The historical branch is a complete design system, not a generic vintage filter.

将 `fixed-era-editorial-print` 编译到当前视觉论证。年代分支是一套完整设计
系统，不是泛黄或做旧滤镜。

```text
Create {{ARTIFACT_KIND}} for {{AUDIENCE}} at {{ASPECT_RATIO}}.

The upstream visual argument is authoritative:
- First read: {{FIRST_READ}}
- Physical action: {{PHYSICAL_ACTION}}
- Concrete evidence: {{CONCRETE_EVIDENCE}}
- Era branch and rationale: {{TARGET_ERA_BRANCH}} / {{ERA_RATIONALE}}
- Text handling: {{TEXT_HANDLING}}

Use the Fixed-Era Editorial Print Pattern. Hold one declared era branch fixed
across typography, limited-color planes, geometry, print pressure, paper, and
active whitespace. Make {{PHYSICAL_ACTION}} and {{CONCRETE_EVIDENCE}} legible
before texture. Select Woodcut Action, Quiet Cover, or Type-Geometry Plate only
when the supplied argument supports that family.

Treat the result as a newly authored contemporary editorial plate. Use a
controlled palette budget and era-appropriate display type; keep exact copy
short and checked or reserve aligned regions for deterministic typesetting.
Paper, grain, and registration marks are subordinate to action and hierarchy.

Avoid generic nostalgia, yellowed-paper-only styling, propaganda imitation,
historical slogans, celebrities, uniforms, flags, copied posters, smooth 3D,
cinematic lighting, random text, logos, signatures, and watermarks. {{FORBIDDEN}}
```

## Slot Guidance / 槽位说明

- `TARGET_ERA_BRANCH`: one fixed branch for the whole output set.
- `ERA_RATIONALE`: explain the visual system it unlocks, not a historical name drop.
- `PALETTE_BUDGET` and `WHITESPACE_PLAN`: keep them explicit in the upstream score.
- `FORBIDDEN`: forbid source identities and topic-specific factual errors.

## Fidelity Gate / 保真门

- Typography, geometry, palette, print pressure, and whitespace read as one era system.
- Subject and action remain legible with paper and grain removed.
- Three outputs vary composition family, not only tint or distress.
- No copied historical identity or slogan is needed for recognition.
