## External Source Lineage / 外部来源谱系

Primary source lineage:

```text
https://github.com/helloianneo/ian-handdrawn-ppt
https://github.com/helloianneo/ian-xiaohei-illustrations
```

Use these sources to understand the grammar, not to copy the protagonist,
example images, page-deck identity, or upstream style assets as GanFan IP.

Reusable grammar extracted from the source lineages:

- `handdrawn-page-dna`: near-white canvas, thin black handdrawn line, restrained
  Chinese text, light marker colors, and strong whitespace;
- `article-body-focus`: extracted from the broader 21:9 cover / 16:9 page-image
  deck workflow into a body-illustration pattern;
- `character-ip`: converted into the OVG `Worker species` slot, with GanFan
  threadball as the default;
- `composition-patterns`: workflow, system local, before/after, character
  state, concept metaphor, method layers, map route, mini comic;
- `prompt-template`: converted into OVG adapter slots;
- `qa-checklist`: converted into pass criteria and failure modes.

从来源 skill 抽取的通用语法：

- `handdrawn-page-dna`：近白画布、细黑手绘线、克制中文文字、淡色标记和强留白；
- `article-body-focus`：从更大的 21:9 封面 / 16:9 页面图 deck 工作流里抽出正文插图范式；
- `character-ip`：转成 OVG 的 `Worker species` 插槽，默认使用 GanFan 线团小工；
- `composition-patterns`：workflow、系统局部、前后对比、角色状态、概念隐喻、方法分层、地图路线、小漫画分镜；
- `prompt-template`：转成 OVG adapter slots；
- `qa-checklist`：转成通过标准和失败模式。

## Do / Don't / 做与不做

Do:

- keep one clear physical action;
- keep the object concrete for beginners;
- use labels as anchors, not paragraphs;
- preserve large white space;
- let the worker carry the meaning.

Don't:

- make a formal flowchart;
- make the worker a cute mascot;
- make the machine too large or realistic;
- replace article-body clarity with cleverness;
- reuse the external source protagonist as GanFan-owned IP.

要做：

- 保留一个清楚的物理动作；
- 物件对小白要具体；
- 标注做锚点，不写成段落；
- 保留大块留白；
- 让小工承担意义。

不要做：

- 画成正式流程图；
- 把小工画成可爱吉祥物；
- 机器过大或过真实；
- 为了聪明牺牲正文配图的一眼可懂；
- 把外部来源主角当作 GanFan 自有 IP 复用。
