## Do / Don't / 做与不做

Do:

- keep one clear physical action;
- keep the object concrete for beginners;
- use labels as anchors, not paragraphs;
- preserve large white space;
- let the worker carry the meaning.

Don't:

- make a formal flowchart;
- make the worker a cute mascot;
- make the machine too large or realistic;
- replace article-body clarity with cleverness;
- reuse the external source protagonist as GanFan-owned IP.

要做：

- 保留一个清楚的物理动作；
- 物件对小白要具体；
- 标注做锚点，不写成段落；
- 保留大块留白；
- 让小工承担意义。

不要做：

- 画成正式流程图；
- 把小工画成可爱吉祥物；
- 机器过大或过真实；
- 为了聪明牺牲正文配图的一眼可懂；
- 把外部来源主角当作 GanFan 自有 IP 复用。
