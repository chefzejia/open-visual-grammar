# Reference Images / 参考图

These images are operator-approved calibration references for the pattern. They
show how exact short text can become the visual object through one semantic
relationship; they are not fixed prompt recipes.

这些图片是经过人工确认的 Pattern 校准参考。它们说明一句短文本如何通过单一语义关系成为视觉主体，不是固定 Prompt 配方。

## `boundary-loosening.webp`

![Boundary loosening semantic concept poster](boundary-loosening.webp)

Source:

```text
Public-safe thesis derived from a GanFan article about Agent changing personal
capability boundaries. Generated at 1536 x 1024 and stored as lossless WebP.
```

Why it belongs:

- the exact phrase `边界正在松动` is the first and dominant read;
- the rigid black frame acts on the word `边界` instead of sitting behind it as
  decoration;
- the rest of the sentence physically opens the same frame, making the
  correction visible without a separate illustration;
- two restrained vermilion seams mark the points of release;
- warm paper, black type, and one accent color keep the result editorial and
  legible at feed size.

保留原因：

- `边界正在松动` 是第一眼且唯一支配性的阅读内容；
- 黑色硬框直接作用于“边界”二字，而不是作为文字背后的装饰；
- 后半句话把同一个框撑开，不依赖独立插图也能让修正关系可见；
- 两处克制的朱红断点标出边界松开的受力位置；
- 暖纸、黑字和单一强调色保持了编辑海报质感，并能在信息流尺寸阅读。

What it does not prove:

- every topic should use a frame, broken border, vermilion accent, or this
  exact phrase;
- image generation can be trusted to render unreviewed Chinese text correctly;
- a visually strong relation can replace a weak or unsupported source claim;
- longer copy, dense explanations, UI proof, or multi-step diagrams belong to
  this pattern.

参考不能证明：

- 每个主题都应该使用边框、断裂结构、朱红色或同一句文字；
- 生图模型生成的中文可以未经检查直接使用；
- 有冲击力的视觉关系可以替代薄弱或无证据的正文主张；
- 长文案、密集解释、界面证据或多步骤图解适合这个 Pattern。
