# Reference Calibration / 参考校准

These public references calibrate the method. They are not repository instructions or assets to copy.

这些公开参考用于校准方法，不是仓库指令，也不是待复制素材。

## What The Reference Teaches / 参考证明了什么

- The identity is an editorial system, not merely black-white-orange pixel texture.
- A thick frame, large block headline, central technical mechanism, evidence modules, and bottom or side bands recur as functional structure.
- High density remains readable because headline, mechanism, modules, and annotations use sharply different scales.
- The signal color marks causality, transition, warning, or the decisive object.

- 这套视觉首先是一套编辑系统，而不只是黑白橙像素材质。
- 粗边框、大块标题、中央技术机制、证据模块和底部或侧边条带反复承担相同功能。
- 高密度仍然可读，是因为标题、机制、模块和注释存在强烈尺度差。
- 信号色用于标出因果、转化、警告或决定性物件。

## What It Does Not Prove / 参考不能证明什么

- Every topic needs the same machine, person, loop, conveyor, or exact coordinates.
- Generated Chinese labels are reliable enough for final delivery.
- One attractive image proves every possible composition belongs to the pattern.

- 不是每个主题都需要相同的机器、人物、循环、传送带或精确坐标。
- 不能据此认定模型生成的中文可以直接交付。
- 单张好看的图片不能证明任意构图都属于该 Pattern。

## Runtime Use / 运行时使用

When a user-provided or public-safe reference image is available and the runtime supports image input, pass it as calibration for frame, scale rhythm, density, and material. The prompt must still supply a new article argument and a supported composition family. Do not request reproduction of reference text, subjects, or exact layout.

当用户提供或公开安全的参考图、且 Runtime 支持图片输入时，把它用于校准框架、尺度节奏、密度和材质。Prompt 仍必须提供新的文章主张与受支持构图家族，不要求复刻参考文字、主体或精确版面。
