## What It Teaches / 可吸收的方法

- A real source photograph is the identity authority; preserve three to five visible anchors before adding material or typography.
- Before reference search, freeze four visual decisions: subject treatment, active background, typography behavior, and one non-default interaction or layout action.
- Use one primary reference that demonstrates a complete mechanism, not a moodboard or palette. A neutral sparse guide can lock exact text, axes, reading order, and overlap without becoming the final style.
- Ask the image model to perform semantic extraction, spatial repair, background reconstruction, local material, and type-image interaction in one coherent world.
- For same-place multi-photo work, reconstruct a shared perspective, light direction, contact surface, and edge language instead of preserving equal photo rectangles.
- Keep factual claims typed as verified, observed, or user-confirmed; keep long exact copy deterministic; perform one readback before user-directed iteration.

## What It Does Not Prove / 它不能证明什么

- It does not prove a universal Chinese, antique, travel, paper, or architectural surface style.
- It does not justify copying the source skill's reference plates, recipes, font specimens, scripts, or exact prompts.
- It does not replace OVG's upstream visual argument, Pattern selection, or runtime contract.
- It does not make every photo suitable for semantic recompose; source identity and factual boundaries still gate the route.

## Transfer Test / 迁移测试

- A historic building poster can use the contract with a protected roofline and a title sharing one eave edge.
- A local food or craft-shop poster can use the same contract with a preserved object/food structure, source-derived palette, and one shared scene field.
- A character-led everyday city note remains in `city-observation-poster` when the character and daily action are primary; Yingzao's route is for source-photo identity and art-directed place reconstruction.
