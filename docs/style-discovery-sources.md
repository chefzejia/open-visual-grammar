# Style Discovery Sources / 风格发现来源地图

This document routes external inspiration into OVG's reverse-engineering
workflow. It is not a bookmark dump and it does not grant reuse rights for any
image. Start with `skills/ovg-style-reverse/SKILL.md`, collect a small coherent
reference group, and adopt only method-level learning.

本文把外部灵感来源接入 OVG 的逆向流程。它不是书签堆，也不代表自动获得图片使用权。先阅读
`skills/ovg-style-reverse/SKILL.md`，再收集一组小而一致的参考，最后只采纳方法级结论。

## Current Taste Signals / 当前偏好信号

The user-selected YouMind sources repeatedly favor six visual behaviors:

1. **Reduction before detail:** a small number of lines, planes, or objects must carry the first read.
2. **Materialized imperfection:** crayon pressure, charcoal grain, torn paper, dry brush, wash, or print misregistration remains visible.
3. **Limited color:** paper plus one or two ink roles is preferred over unrestricted palettes.
4. **Editorial hierarchy:** image and type share axes, depth, or page rhythm instead of behaving as separate decoration.
5. **Childlike warmth with control:** naive marks are welcome when identity, action, and composition remain intentional.
6. **Reusable systems:** slide families, cover routes, and repeatable character logic matter more than one attractive image.

用户选择的 YouMind 来源反复表现出六种偏好：先减法后细节、可见手工不完美、限制色、编辑层级、
受控童真，以及可以跨页面或跨主题复用的系统。

These signals are search axes, not permanent taste labels. A source belongs only
when it teaches a transferable relation or boundary.

这些信号是检索轴，不是永久品味标签。只有能说明可迁移关系或边界的来源才值得进入 OVG。

## High-Signal Source Tiers / 高信号来源分层

### 1. Applied Design Archives / 真实应用设计档案

Use these to study complete systems: hierarchy, typography, image treatment,
format families, and production constraints.

| Source | Best evidence | Intake caution |
| --- | --- | --- |
| [AIGA Design Archives](https://designarchives.aiga.org/) | identity systems, posters, editorial and campaign work | record designer, client, year, and artifact; do not reduce a project to a color palette |
| [BP&O](https://bpando.org/) | brand and editorial systems shown across several applications | separate brand-specific marks from reusable layout behavior |
| [The Brand Identity](https://the-brandidentity.com/) | contemporary identity, typography, packaging, and art direction | prefer projects with several artifacts over one hero mockup |
| [Fonts In Use](https://fontsinuse.com/) | real typography roles, script pairing, scale, and production context | typeface names are evidence metadata, not a complete Pattern |
| [Poster House](https://posterhouse.org/) | poster hierarchy, public messaging, print processes, historical context | preserve attribution and distinguish period convention from transferable structure |

### 2. Illustration And Picture-Book Selection / 插画与绘本评选

These sources are stronger than generic image feeds because selection is tied to
storytelling, audience, sequence, and craft.

| Source | Best evidence | Intake caution |
| --- | --- | --- |
| [Bologna Children's Book Fair](https://www.bolognachildrensbookfair.com/) | contemporary picture-book illustration, sequence, age temperature, narrative economy | collect several pages or works from one visual system; do not infer a book grammar from a cover alone |
| [World Illustration Awards](https://theaoi.com/world-illustration-awards/) | editorial, book, advertising, and experimental illustration with category context | category fit does not prove transfer; write down the visual action and density |
| [The Original Art](https://societyillustrators.org/awards/the-original-art/) | published children's books and narrative illustration | distinguish character consistency from surface material |
| [dPICTUS](https://dpictus.com/) | picture-book selections, publishers, and visual storytelling | use publisher and title metadata for attribution; keep scans external unless rights are clear |

### 3. Museum And Open Collections / 博物馆与开放馆藏

Use these for material history, composition, print processes, ornament systems,
and public-domain calibration. They are especially useful for avoiding vague
labels such as “vintage” or “oriental”.

| Source | Best evidence | Intake caution |
| --- | --- | --- |
| [The Met Open Access](https://www.metmuseum.org/about-the-met/policies-and-documents/open-access) | public-domain art and design objects with metadata | verify the individual object's rights marker before vendoring an image |
| [Rijksmuseum](https://www.rijksmuseum.nl/en/rijksstudio) | print, painting, decorative art, and high-resolution detail | use medium, date, and process as evidence; avoid named-artist imitation as a Pattern |
| [Cooper Hewitt Collection](https://collection.cooperhewitt.org/) | posters, textiles, objects, pattern systems, and design metadata | extract structure or process rather than surface ornament alone |
| [NYPL Digital Collections](https://digitalcollections.nypl.org/) | historical posters, book pages, maps, ephemera, and illustration | check item-level rights and keep archival context |
| [Internet Archive](https://archive.org/) | scanned design annuals, magazines, manuals, and public-domain children's books | a scan may be public to view without being free to republish; record the source edition |

### 4. Regional Design Awards And Type Archives / 地区设计奖与字体档案

Use these to reduce a Western-only bias and to study script-aware typography.

| Source | Best evidence | Intake caution |
| --- | --- | --- |
| [JAGDA](https://www.jagda.or.jp/en/) | Japanese graphic design, posters, identity, and publication work | separate Japanese-language hierarchy from a generic “Japanese style” label |
| [Tokyo TDC](https://tokyotypedirectorsclub.org/en/) | expressive typography and type-image relations | extract glyph behavior, hierarchy, and composition; do not copy display lettering |
| [Golden Pin Design Award](https://www.goldenpin.org.tw/en/) | East Asian communication, packaging, product, and spatial systems | distinguish the artifact kind before extracting style |

### 5. Discovery Boards / 发现型社区

[Are.na](https://www.are.na/), [Behance](https://www.behance.net/), and
[Savee](https://savee.it/) are useful for finding clusters and creators. Treat
them as leads, not final evidence. Follow each item to the original portfolio,
publisher, studio, award page, or collection record before adoption.

Are.na、Behance 和 Savee 适合发现聚类与创作者，但只能作为线索。正式入库前，应回到原始作品集、出版社、
工作室、奖项页面或馆藏记录。

## Search Recipes / 检索组合

Search by four axes instead of one broad style word:

```text
material + composition + emotional temperature + artifact
```

Examples:

- `monoline + large negative space + quiet + editorial cover`
- `risograph + recurring character + warm + picture book sequence`
- `charcoal + geometric color field + intellectual + magazine illustration`
- `torn paper + type portrait occlusion + confrontational + video thumbnail`
- `woodcut + strict grid + calm + research slide deck`
- `crayon + imperfect proportion + playful + children's picture book`

Use controlled comparison whenever possible: keep one subject, claim, or page
structure fixed and compare six to twelve references. This reveals whether the
real invariant is line, palette, composition, material, typography, or merely
the original subject.

尽量使用受控比较：固定一个主体、论点或页面结构，对照六到十二个参考。这样才能判断真正稳定的是线条、
配色、构图、材质、排版，还是原始题材本身。

The first bounded implementation is recorded in

The sampled Met woodcut records calibrate the existing

第一轮有限采样记录在

## Intake Packet / 入库包

For each source cluster, record:

```text
Source URLs:
Creators / studios:
Artifact kinds:
Rights status:
Reference count:
Stable first read:
Stable composition behavior:
Stable material and line behavior:
Stable color roles:
Stable type-image relation:
Variables:
What appears accidental:
Two unrelated transfer topics:
Existing Pattern fit:
OVG disposition:
```

A useful cluster usually contains three to eight related works and at least one
clear boundary example. More images do not compensate for missing method-level
judgment.

一组有效聚类通常包含三到八件相关作品，以及至少一个清晰边界样本。缺少方法级判断时，增加图片数量也没有用。

## Rejection Rules / 拒绝规则

Keep a source out of OVG when it is only:

- an attractive palette with no stable composition;
- one viral image with no related work;
- a named artist label without visible invariants;
- a prompt dump with no reviewed output;
- a proprietary character or brand system that cannot transfer safely;
- an image whose rights or source cannot be established;
- a mood board whose items teach contradictory methods.

当来源只有漂亮配色、孤立爆款图、没有可见不变量的艺术家标签、未经人审的 prompt 堆、不可安全迁移的
专有角色或品牌、权利与来源不明的图片，或彼此方法矛盾的 mood board 时，不进入 OVG。
