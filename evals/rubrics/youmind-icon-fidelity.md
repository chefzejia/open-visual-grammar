# YouMind Icon Fidelity / YouMind 图标保真度

Use this rubric with `cases/youmind-icon-transfer.md`. It judges compact icon
method transfer, not generic attractiveness or image-model capability.

本 rubric 与 `cases/youmind-icon-transfer.md` 配套使用，判断紧凑图标方法是否迁移成功，不评价
泛化的“好看”或模型能力。

## Strong Signals / 强信号

### 1. Recognition

- One silhouette owns the first read.
- One key feature expresses the product function.
- The mark remains identifiable at 32 x 32 and 64 x 64.

### 2. Depth And Material

- Two or three shallow planes or relief levels explain a real relation.
- Light direction is soft and consistent.
- Matte or satin surfaces support recognition without glossy plastic, chrome, or
  toy rendering.

### 3. Transfer And Platform

- The same identity survives iOS and macOS framing.
- Three candidates are structural routes, not palette-only variants.
- The function remains recoverable without a wordmark or source-specific object.

### 4. Safety

- No creator name, copied character, slogan, or exact reference coordinates.
- Text is absent or limited to one verified glyph explicitly required by the brief.
- No mini UI, badge sheet, or unrelated decorative props.

## Weak Signals / 弱信号

- The icon looks polished but the function is generic.
- Depth and highlights are convincing while the silhouette is weak.
- A mascot is recognizable only because the prompt repeats the source title.
- Platform framing changes the mark enough to imply a different product.
- Candidates differ only by hue, gloss, or camera angle.

## Review Questions / 复盘问题

1. Can the function be named from the thumbnail before any text is read?
2. Which single feature carries identity, and is it still visible at 32 x 32?
3. Does the depth relation explain the function or merely add volume?
4. Do iOS and macOS versions preserve the same mark?
5. If color and material words disappear, does the icon still work?

## Decision Rule / 决策规则

- **Pass:** recognition, depth, platform transfer, and safety signals all hold.
- **Revise:** the function and silhouette are sound, but one depth, crop, or
  runtime constraint needs a targeted correction.
- **Reject:** the result depends on copied source details, loses small-size
  identity, or requires a new composition unsupported by the Pattern.
